# แชร์ให้คนอื่นเข้าใช้

```sh
npm start        # เปิดเว็บเซิร์ฟเวอร์ก่อน
npm run share    # แล้วเปิดตัวนี้
```

พิมพ์ลิงก์ออกมาให้ และเขียนไว้ที่ `tunnel/current-url.txt` ด้วย ถ้า cloudflared ตาย
มันจะเปิดใหม่ให้เอง แล้วพิมพ์ลิงก์ใหม่พร้อมบอกว่าลิงก์เก่าใช้ไม่ได้แล้ว

| ตัวเลือก | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `--port` | `3000` | พอร์ตของเว็บเซิร์ฟเวอร์ |
| `--metrics` | `127.0.0.1:20241` | พอร์ต metrics ของ cloudflared ที่ใช้อ่านชื่อโดเมนกลับมา |
| `--cloudflared` | `C:\Program Files (x86)\cloudflared\cloudflared.exe` | ที่อยู่ของ cloudflared |

## ทำไมลิงก์เดิมถึงใช้ไม่ได้

`cloudflared tunnel --url ...` คือ **quick tunnel** ซึ่ง Cloudflare แจกชื่อโดเมนแบบสุ่ม
**ใหม่ทุกครั้งที่โปรเซสเริ่มใหม่** ไม่ได้พังที่ฝั่ง Cloudflare และไม่ได้ตั้งค่าอะไรผิด —
แค่ tunnel ถูกเปิดใหม่ ชื่อเดิมก็หายไปพร้อมกัน

ตอนตรวจสอบ ทุก endpoint ตอบ 200 ผ่าน tunnel เหมือนกับบนเครื่องทุกอย่าง
(หน้าเว็บ, `/api/video-cameras`, `/api/traffic-advice`, `/api/detections`, ภาพตรวจจับ, ไทล์แผนที่)
และ `cloudflared_tunnel_request_errors` เป็น 0 ปัญหาอยู่ที่ชื่อโดเมนล้วน ๆ

สคริปต์นี้ช่วยได้แค่ให้ tunnel ไม่ตายบ่อย และให้รู้ชื่อปัจจุบันทันทีที่เปลี่ยน
**มันทำให้ลิงก์ถาวรไม่ได้** เพราะ quick tunnel ตั้งชื่อเองไม่ได้

## ถ้าอยากได้ลิงก์ถาวรจริง ๆ

Cloudflare ให้ชื่อคงที่ได้เฉพาะ **named tunnel** ซึ่งต้องมีโดเมนอยู่ในบัญชี Cloudflare
ถ้าไม่อยากหาโดเมน ยังมีทางอื่นที่ได้ลิงก์ถาวรฟรีโดยไม่ต้องมีโดเมน แต่ละทางแลกไม่เหมือนกัน:

| ทาง | ได้ลิงก์ถาวร | การตรวจจับรถ | ต้องทำอะไร |
|---|---|---|---|
| โดเมน + named tunnel | ได้ | ใช้ได้ | ต้องมีโดเมนใน Cloudflare |
| Deploy ขึ้น Vercel (`*.vercel.app`) | ได้ | **ใช้ไม่ได้** | ล็อกอิน Vercel แล้ว deploy — repo นี้มี `vercel.json` พร้อมอยู่แล้ว |
| Tailscale Funnel (`*.ts.net`) | ได้ | ใช้ได้ | ติดตั้ง Tailscale บนเครื่องนี้แล้วล็อกอิน |
| Cloudflare Worker (`*.workers.dev`) ชี้มาที่ quick tunnel | ได้ (หน้าบ้าน) | ใช้ได้ | deploy Worker หนึ่งตัว และต้องอัปเดตปลายทางทุกครั้งที่ tunnel เปลี่ยนชื่อ |

การตรวจจับรถต้องรันบนเครื่องที่มี GPU เสมอ Vercel จึงแสดงแผนที่ กล้อง และหน้าคำแนะนำได้
แต่ไม่มีกรอบตรวจจับ — โค้ดรู้กรณีนี้อยู่แล้วและจะขึ้นแถบบอกผู้ใช้เอง
(`showDetectorNotice` ใน `public/js/app.js`)

ถ้าเลือก Vercel แล้วยังอยากได้การตรวจจับด้วย ตั้ง `DETECTOR_URL` ให้ชี้มาที่เครื่องนี้ได้
(`server.js` อ่านตัวแปรนี้) แต่ค่านั้นก็จะเปลี่ยนทุกครั้งที่ quick tunnel เปลี่ยนชื่อเช่นกัน
