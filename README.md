# กล้องจราจรกรุงเทพ 🚦📹

ดึงกล้องจราจรจาก **API ของ Longdo** ตรง ๆ อัดวิดีโอทุกกล้องต่อเนื่องเป็นคลิปละ 10 นาที
เก็บไว้ที่ D:/CCTV แล้วเล่นย้อนบนเว็บ และแปลงสีถนนจากไทล์จราจรเป็นคำแนะนำการปล่อยรถรายถนน

```sh
npm start        # เว็บเซิร์ฟเวอร์ พอร์ต 3000
npm run record   # ตัวอัดคลิป (คนละโปรเซส)
npm run share:ts # เปิดลิงก์สาธารณะผ่าน Tailscale Funnel
```

แล้วเปิด **[http://localhost:3000](http://localhost:3000)**

การตรวจจับสดตอนกดเข้าดูกล้องเดี่ยวต้องเปิดอีกตัว:

```sh
detector/.venv/Scripts/python.exe detector/detect.py --weights detector/weights/yolo11x.pt
```

## กล้องมาจากไหน

`https://camera.longdo.com/feed/?command=json` — แคตตาล็อกเดียวกับที่แผนที่ Longdo อ่าน
เปิดสาธารณะ ไม่ต้องใช้ key คืนกล้องทั่วประเทศ 296 ตัว เป็น **HLS (H.264) จริง** ที่เบราว์เซอร์
เล่นได้ตรง ๆ และมี `Access-Control-Allow-Origin: *`

`server.js:VIDEO_CATALOGUE_URL` กรองเหลือเฉพาะกล้องในกล่องกรุงเทพและปริมณฑล
แล้วตัดกล้องที่สตรีมตายออกด้วยการลองต่อจริงหนึ่งครั้งต่อรอบรีเฟรช

> `https://traffic.longdo.com/camera.json` เป็นข้อมูลชุดเดียวกัน (294 จาก 296 รายการ
> ทุก field ตรงกัน) ไม่ต้องเปลี่ยนไปใช้

## หน้าเว็บและฟีเจอร์เด่น (Modern Dashboard UI)

- **แถบนำทางด้านข้าง (Left Sidebar Navigation)**: ย้ายเมนูนำทางหลัก 3 ตัว (กล้องสด, แผนที่จราจร, คำแนะนำปล่อยรถ) มาไว้ด้านข้างสไตล์ Modern Dashboard พร้อมวิดเจ็ตแสดงดัชนีจราจรรวมแบบเรียลไทม์ และนาฬิกาดิจิทัล
- **Custom Watchlist & Multi-View (4–9 จอ)**: ปักหมุดกล้องที่ใช้สัญจรบ่อยเพื่อดูสดพร้อมกันหลายจอ รองรับการสลับตาราง Grid 2 คอลัมน์ (2x2), 3 คอลัมน์ (มาตรฐาน) และ 4 คอลัมน์ พร้อมปุ่มเพิ่มกล้องยอดนิยม 4 จุดทันที
- **Interactive Map & Pop-up Preview**: หมุดกล้องบนแผนที่จะเปลี่ยนสีตามความหนาแน่นจริง (เขียว = คล่องตัว, เหลือง = ชะลอตัว, แดง = ติดขัดสะสมพร้อมเอฟเฟกต์ Radar Pulse) เมื่อคลิกหมุดจะมี Pop-up เล่นวิดีโอสด พร้อมปุ่ม Picture-in-Picture (PiP), เต็มจอ และปักหมุดลง Watchlist
- **Picture-in-Picture (PiP)**: รองรับการย่อหน้าต่างวิดีโอลอยดูมุมจอได้ทั้งจากการ์ดกล้อง, ป็อปอัปบนแผนที่ และหน้าต่างรายละเอียด AI
- **Smart Filter & Search**: ค้นหาตามชื่อถนน ทางแยก หรือรหัสกล้อง พร้อม Filter Pills กรองด่วนตามสภาพจราจร (`ทั้งหมด`, `⭐ Watchlist`, `🚨 ติดขัด`, `🟡 ชะลอตัว`, `🟢 คล่องตัว`) และคีย์ลัดกด `/` เพื่อค้นหาทันที
- **การ์ดกล้อง & ตรวจจับ AI**: การ์ดแสดงสถานะ `LIVE` และแท็กสภาพจราจร พร้อมแสดงจำนวนยานพาหนะและสถิติแยกประเภทรถจากโมเดลตรวจจับแบบเรียลไทม์

## API

| Endpoint | คืนอะไร |
|---|---|
| `GET /api/video-cameras` | รายชื่อกล้องที่สตรีมใช้ได้จริง พร้อม `hls` และพิกัด |
| `GET /api/recordings` | รายการคลิปของแต่ละกล้อง เรียงตามเวลา |
| `GET /api/recording/<กล้อง>/<วัน>/<เวลา>.mp4` | คลิปหนึ่งอัน |
| `GET /api/detections` | จำนวนรถและกรอบจากตัวตรวจจับ ตอบ `enabled:false` ถ้าไม่ได้เปิด |
| `GET /api/traffic-advice` | คำแนะนำรายถนน |
| `GET /api/traffic-index` | ดัชนีจราจรรวมของ Longdo |

## เคยมีกล้อง BMA 611 ตัว

โปรเจกต์นี้เริ่มจากการพร็อกซีกล้อง BMA (`cpudapp.bangkok.go.th/bmatraffic`) ซึ่งเป็น
ภาพนิ่งรีเฟรชเรื่อย ๆ ต้อง handshake session ต่อกล้อง และ Cloudflare ฝั่งเขาตอบ
bot challenge ให้กับ IP ของศูนย์ข้อมูล — เซิร์ฟเวอร์ที่ deploy ไว้จึงดึงภาพเองไม่ได้เลย

วัดแล้วพบว่ามันแพงและคุณภาพต่ำกว่าทางเลือกที่มี: ภาพ **352×288** ดึงได้ **0.24–0.36
ภาพต่อวินาที** (เพิ่ม worker 4 เท่าได้เร็วขึ้นแค่ 1.5 เท่า เพราะคอขวดคือ handshake)
และที่ความละเอียดนั้นโมเดลนับเกินจริงจากกรอบที่เกาะโครงสร้างสะพาน ส่วนมอเตอร์ไซค์
แทบไม่เจอเลย

กล้อง Longdo ให้ H.264 ที่ 704×576 ถึง 1920×1080 ไม่ต้อง session ไม่ต้องพร็อกซี
จึงเหลือแค่ทางนั้น และโค้ดฝั่ง BMA ทั้งหมดถูกถอดออกแล้ว
