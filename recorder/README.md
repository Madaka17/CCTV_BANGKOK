# ตัวบันทึกภาพกล้อง

เว็บแสดงว่ากล้องเห็นอะไร**ตอนนี้** ตัวนี้เก็บว่ากล้องเคยเห็นอะไร — เก็บภาพจากทุกกล้อง
เป็นระยะ พอหมดวันก็ต่อเป็นวิดีโอหนึ่งไฟล์ แล้วลบทิ้งเมื่อเกินกรอบที่ตั้งไว้

```sh
npm run record          # เก็บไปเรื่อย ๆ
npm run record:once     # เก็บรอบเดียวแล้วจบ (ไว้ทดสอบ)
```

| ตัวเลือก | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `--out` | `D:/CCTV` (หรือ `CCTV_DIR`) | ที่เก็บ |
| `--interval` | `90` | วินาทีระหว่างรอบ |
| `--keep-days` | `5` | เก็บกี่วัน |
| `--workers` | `8` | ดึงพร้อมกันกี่กล้อง |
| `--video-fps` | `10` | อัตราเล่นของวิดีโอที่ต่อแล้ว |

## ทำไมต้อง 90 วินาที

ทุกเฟรมต้องเปิดการเชื่อมต่อ HLS ใหม่ — playlist, segment แรก, แล้วค่อยได้เฟรม
วัดรอบเก็บครบทุกกล้องได้ **77 วินาทีที่ 8 workers และ 73 วินาทีที่ 16 workers**
เพิ่ม thread ไม่ช่วยเพราะคอขวดคือการต่อเชื่อม ไม่ใช่จำนวน thread

ในการใช้จริงรอบหนึ่งกินเวลา 79–126 วินาที แล้วแต่ว่ากล้องตัวไหนอืด ถ้ารอบไหนเกิน 90
วินาที รอบถัดไปจะเริ่มทันที ระยะห่างจริงจึงลอยอยู่ประมาณ 75–130 วินาที

**เก็บทุก 10 วินาทีทำไม่ได้** จะได้ต้องเปิดสตรีมค้างไว้ 27 เส้นพร้อมกัน ซึ่งชนกับ
แบนด์วิดท์ที่วัดไว้ใน `public/js/app.js` — แต่ละสตรีมกิน 0.3–6.8 Mbps และแปดเส้น
ขนานกันแชร์กันได้แค่ 2.5 Mbps รวม

## 90 วินาทีใช้ทำอะไรได้ ใช้ทำอะไรไม่ได้

**ไม่ได้:** ตามรอยรถทีละคัน รถวิ่งพ้นเฟรมไปนานแล้วระหว่างสองภาพ ตัวนี้จึงไม่ใช่
ตัวตรวจจับอีกตัว ถ้าต้องการนับรถแบบ tracking ให้ใช้ `detector/` ซึ่งทำงานที่ 7-8 fps
บนกล้องที่มีคนเปิดดูอยู่

**ได้:** ความหนาแน่นของแต่ละจุดตามช่วงเวลา ซึ่งเป็นสิ่งที่ `logger/` (เก็บสีถนนจาก
ไทล์ทุก 5 นาที) ต้องการเพื่อให้พยากรณ์ได้ — อันนั้นบอกว่าถนน*ดูแน่นแค่ไหน* อันนี้เก็บ
ภาพจริงไว้ให้ย้อนดูได้ว่าตอนนั้นเกิดอะไรขึ้น

## พื้นที่

วัดจริง: 27 กล้องต่อรอบราว 3.1 MB

| เก็บเป็น | ต่อวัน | 5 วัน |
|---|---|---|
| JPEG | ~3.0 GB | ~15 GB |
| ต่อเป็นวิดีโอ mp4v | ~0.5 GB | **~2.7 GB** |

เฉพาะวันที่กำลังเก็บอยู่เท่านั้นที่เป็น JPEG วันที่ผ่านไปแล้วถูกบีบเหลือ 18%
(วัดจริง: 18 เฟรม 704×576 = JPEG 974 KB → mp4v 175 KB)

ถ้าลง `openh264-2.5.0-win64.dll` เพิ่ม OpenCV จะเข้ารหัส H.264 ได้และเล็กลงอีกราวครึ่ง
ตอนนี้ยังไม่มีบนเครื่องนี้ โค้ดจึงใช้ mp4v ซึ่งมีให้เสมอ
